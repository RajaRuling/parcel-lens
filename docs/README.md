# Parcel Lens static evidence site

Open index.html locally. No build step, remote font, image service, inference endpoint or tracker is required. Files under this directory form the complete static site; nothing has been published.

Version 2 results come from assets/evidence.js and the equivalent downloadable assets/results.json. Every displayed gallery image is original procedural CC0 work. All standard and shifted test metrics, negative acceptance findings, CIs and limits come from the frozen experiment. Research notes are copied into research/ by the result command. The gallery's optional boxes are synthetic truth, not learned predictions.

Screenshots at 390 px and 1280 px are in screenshots/. Browser checks are recorded in screenshots/browser-checks.json. Real-image accuracy is untested; production auto-clear is disabled.
